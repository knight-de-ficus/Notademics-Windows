# 空行折叠策略测试

> 使用方法：
> 1. 复制本文件全部内容到 Typora（粘贴为 Markdown 源码）
> 2. 逐场景观察"场景N-引用行"到"场景N-结束"之间有几个【可见】空行
> 3. 记录每个可见空行是否带 `>`（引用内空行）还是纯空白（普通空行）
> 4. 按文末模板回报结果
