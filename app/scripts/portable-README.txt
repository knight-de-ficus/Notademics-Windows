Notademics portable package
===========================

1. Extract the whole ZIP archive to a writable directory.
2. Keep Notademics.exe and the resources directory together.
3. Run Notademics.exe. No installation is required.

Notademics uses the Windows WebView2 runtime. Current Windows 10/11 systems
normally already provide it. Application settings and recovery data are stored
in the current Windows user's application data directories; they are not kept
inside this portable package.
